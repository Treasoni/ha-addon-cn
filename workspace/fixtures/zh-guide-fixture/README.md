# Zh Guide Fixture

## 简介
一个用于测试中文指南质量门禁的测试 add-on。

## 安装
1. 添加商店仓库：https://github.com/Treasoni/ha-addon-cn
2. 搜索并安装 zh-guide-fixture。

## 配置

| 配置键 | 类型/默认值 | 说明 |
| ------ | ----------- | ---- |
| `token` | 字符串 | 认证令牌。 |
| `poll_seconds` | 整数，默认 `60` | 轮询间隔秒数。 |
| `debug` | 布尔值，默认 `false` | 是否开启调试日志。 |

## 使用 / 访问入口
通过侧边栏 Ingress 访问 Web 界面。
