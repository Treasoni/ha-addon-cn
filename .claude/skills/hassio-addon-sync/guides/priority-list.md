# 首批中文指南候选清单

首批为主流的 ~30 个 add-on 生成中文指南；其余按需用 skill 的 `--gen-guide <slug>` 流程逐个补。

> 仅处理**同步后实际存在**的 slug（某个源没有的会自动跳过）。生成顺序与数量可调整。
